# my-dotfiles
my dotfiles i guess

feel free to use them

## Install
### 1. Install dependencies
Install these packages with your distro's package manager:
- `imagemagick`
- `libsixel` (for image support)
- `kitty`
- `fastfetch`
### 2. Clone
Clone into your home folder.(README.md aren't save)

`git clone https://github.com/FlatPonch/my-dotfiles ~`

or you too lazy, you can download as zip.
